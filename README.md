# Cross-DRL
基于深度强化学习的自动驾驶车辆交叉口通行决策研究——基于Q-learning、DQN及其改进算法的仿真实验 

## SUMO 仿真环境

- [环境搭建和运行](docs/sumo_setup.md)
- [主车状态、动作和 Gymnasium 接口草案](docs/environment_interface.md)
- [三档交通流初次测试记录](docs/calibration.md)

目前提供单路口、固定信号、背景车流、单辆受控主车，以及规则控制和 Q-learning 的初步实现；相关接口仍需组员共同确认。主车可在每回合开始前选择直行、左转或右转，回合内动作仍是纵向加速度。

背景车按概率随机发车，并按 60% 直行、20% 左转、20% 右转随机选择路线；低、中、高密度控制生成需求。使用相同 `reset(seed=...)` 可以复现同一组车流和初始信号相位。
